# .dockerignore

`.dockerignore` lists paths Docker **excludes from the build context** — the
snapshot of the project handed to the build engine before any `COPY` runs. Trimming
it makes builds faster, keeps the final image small, and stops local-only or secret
files from being baked in. It applies to the whole build, so it guards every stage's
`COPY . .` (the [`builder` stage](./dockerfile.md)) at once.

## Why it matters

- **Speed & size.** A smaller context uploads faster and can't bloat image layers.
- **Correctness.** Locally built artifacts (`node_modules`, `.next`) must not be
  copied in — the image rebuilds them itself (`npm ci` in `deps`, `npm run build` in
  `builder`). Copying stale host copies would shadow the fresh build.
- **Secrets.** `.env*` never enters the image; runtime env comes from Compose's
  `environment:` key instead (see [compose.md](./compose.md)).

## What's excluded, and why

Grouped by intent:

**Rebuilt inside the image — never copy the host's copy**
- `node_modules` — reinstalled from the lockfile (`npm ci`) in `deps`.
- `.next`, `out`, `build` — Next build output; regenerated by `npm run build`.
- `coverage`, `*.tsbuildinfo` — test / TypeScript incremental artifacts.

**Secrets & local env**
- `.env*` — kept out of the image entirely; injected at runtime.

**VCS & repo meta**
- `.git`, `.gitignore`, `.dockerignore`, `README.md`, `.claude` — not needed to run
  the app.

**Editor / OS / tooling cruft**
- `.DS_Store`, `.idea`, `npm-debug.log*`.

**Deploy config not needed inside the image**
- `Dockerfile`, `compose*.yaml` — the build's own recipe; nothing in the image reads it.
- `.vercel` — local Vercel link state.

## Interplay with the dev bind-mount

`.next` is ignored here, yet dev still needs a working `.next`. The dev service
bind-mounts your source (`.:/app`) and layers **anonymous volumes** over
`/app/node_modules` and `/app/.next` (see [compose.md](./compose.md)) so the
container's own generated `node_modules`/`.next` aren't shadowed by the host — the
same separation `.dockerignore` enforces for the image build.
